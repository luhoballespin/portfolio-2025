Enfoque

Desarrollo tecnología desde el negocio, no desde el stack.

Mi diferencial es combinar desarrollo backend con conocimiento real de empresas productivas. Antes de escribir una API, analizo cómo circula la información, dónde se repiten tareas, qué datos se pierden y qué decisiones necesitan mejor soporte.

Esa mirada permite construir soluciones útiles para el campo: simples de operar, conectadas con el proceso real y preparadas para crecer.
